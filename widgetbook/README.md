# Widgetbook Laurum

Jalankan dari akar repo: `flutter run -t widgetbook/main.dart`.
Untuk web: `flutter run -d chrome -t widgetbook/main.dart`.

Folder Atoms berisi satu use-case seluruh varian untuk AppText, AppIcon,
AppGap, AppDivider, dan AppCard. AppSvg menunggu SVG produksi pertama.
Galeri menggunakan tema Laurum dan font lokal, tanpa codegen.

Katalog API: docs/design/component_catalog.md.
Kemajuan dan selisih desain: docs/progress/fase-1.md.
Preview golden: test/goldens/.
Format: `dart format --set-exit-if-changed widgetbook`.
