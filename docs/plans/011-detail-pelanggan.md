# Detail Pelanggan dan sheet Edit profil

Lingkup: layar Detail Pelanggan berikut sheet aksi Edit profil (sisa prompt 50).
1. Baseline check_all, baca frame Detail/Edit dan registry.
2. Tes angka fixture, saldo berjalan, edit/validasi, dan nonaktif tanpa menghapus histori.
3. Bagikan ringkasan pelanggan aktif/nonaktif; susun Detail dari widget registry.
4. Sheet edit memakai Notifier, validasi nama/nomor dan duplikat, ConfirmModal nonaktif.
5. Uji navigasi, error/kosong, reaktivitas dan layar sempit; check_all; spec/STATE; commit.

Impor/setor/riwayat mutasi tetap placeholder sampai prompt 51.
Usage diperiksa berkala; jika sisa mendekati 10%, simpan handoff di STATE dan commit.
