# B5 — printer nyata

SELESAI 12 Nov 2026 (irisan 1 dan 2). Rencana: docs/plans/B5-printer.md. BLE lewat
`flutter_blue_plus`, tanpa Figma, tanpa push/merge.

## Hasil

- `EscPosEncoder` mengubah `ReceiptData.lines` menjadi byte ESC/POS: init, rata kiri,
  teks per baris, tinggi ganda untuk ukuran huruf 13, feed 4 baris. ASCII saja;
  karakter lain menjadi `?`. Tanpa perintah potong.
- `PrinterTransport` menjadi seam sempit untuk plugin Bluetooth.
- `EscPosPrintService` memetakan status discover/connect/print/error dan memakai
  encoder. `printServiceProvider` memakai layanan ini pada build backend `drift`.
- `BlePrinterTransport` + `BlePrinterScanner`: pindai 8 detik, hanya perangkat
  bernama, connect 15 detik, pilih karakteristik writable (UUID thermal umum lalu
  fallback), tulis per 180 byte. Galat transport menjadi status aman, bukan crash.
- Izin BLE masuk AndroidManifest dan Info.plist; fitur ditandai belum diuji di iOS.
- `PrinterDevice.id` dipakai sebagai alamat perangkat; tidak ada perubahan UI/state.
