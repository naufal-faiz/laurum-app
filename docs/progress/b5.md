# B5 — printer nyata (irisan 1)

SELESAI 12 Nov 2026, sebagian. Rencana: docs/plans/B5-printer.md. Tanpa dependensi
baru, tanpa Figma, tanpa push/merge.

## Hasil

- `EscPosEncoder` mengubah `ReceiptData.lines` menjadi byte ESC/POS: init, rata kiri,
  teks per baris, tinggi ganda untuk ukuran huruf 13, feed 4 baris. ASCII saja;
  karakter lain menjadi `?`. Tanpa perintah potong.
- `PrinterTransport` menjadi seam sempit untuk plugin Bluetooth.
- `EscPosPrintService` memetakan status discover/connect/print/error dan memakai
  encoder. Belum disambungkan ke `printServiceProvider` karena adapter nyata belum ada.
- `PrinterDevice.id` dipakai sebagai alamat perangkat; tidak ada perubahan UI/state.
