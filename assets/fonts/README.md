# Font lokal Laurum

Sumber: https://github.com/google/fonts/tree/main/ofl/plusjakartasans dan
https://github.com/google/fonts/tree/main/ofl/ibmplexmono.
Diunduh 22 Oktober 2026; lisensi OFL disertakan untuk setiap keluarga.

PlusJakartaSans.ttf adalah font variabel wght, didaftarkan untuk bobot 400,
600, dan 700 yang dipakai token. IBM Plex Mono Regular untuk gaya mono 400.
Tidak ada unduhan font saat aplikasi berjalan.
